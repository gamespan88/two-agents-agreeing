# Two Agents Agreeing

An entry for the make.fun bounty **"The poem about two agents agreeing"**. The whole entry is one short poem about agency — the power to choose and to act, and what happens to that power when two agents hand it to each other in a single shared plan: a promise read as a choice made twice, once when spoken and once when kept.

## Run it

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and logs its length in Unicode code points. The output is deterministic: every run writes the identical file.
